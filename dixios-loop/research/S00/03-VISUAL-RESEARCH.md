# S00 HERO — 03 VISUAL RESEARCH

**Baseline:** `BASELINE_2026_09_05 / S00-HERO`  
**Date checked:** 2026-09-05  
**Phase:** `VISUAL_RESEARCH`  
**Concept locked:** `RESOLVE` — unresolved institutional variety → modeled relationships → coordinated capability  
**Hard rule:** Mexico must become a strong `SITUATED FOCUS`, not a tiny marker or fake coverage map.  
**Scope:** visual grammar, references, composition, materiality and motion language only. No implementation stack is selected here.

---

# 1. Research question

The visual problem is not:

> How do we make a prettier globe?

It is:

> **How can a hero make a large, heterogeneous system remain visibly complex while a specific locus — Mexico — becomes perceptually resolved, legible and ready for action?**

The required visual grammar must simultaneously communicate:

```text
SYSTEM SCALE
+
SITUATED FOCUS
+
RESOLUTION
+
CAPABILITY
```

A successful hero should let a visitor feel that the system is **alive and high-variety**, while Dixios creates selective clarity rather than flattening everything into a dashboard.

---

# 2. Visual principles derived from the concept

## Principle A — Preserve complexity outside the focus

The environment should remain dense, layered and partially unresolved.

The hero should not make the entire globe equally crisp and equally important.

Visual distinction should emerge through **contrast of resolution**:

```text
PERIPHERY = complex / low-certainty / dense / partially latent
FOCUS     = resolved / higher-definition / relationally explicit
```

This is stronger than simply changing color.

---

## Principle B — Mexico should alter the field, not sit on top of it

A marker is an annotation.

The user asked for Mexico to feel larger and more important.

The stronger art-direction move is to make the surrounding system **behave differently around Mexico**:

- local magnification;
- density change;
- directional flow convergence;
- local increase in line precision;
- expanded coordinate scale;
- focus+context distortion;
- radial response;
- secondary detail layer that shares geometry with the global layer.

Mexico therefore becomes a **field condition** rather than a pin.

---

## Principle C — Resolution should be visible as a change of information state

Before/after frames must be meaningfully different.

Examples:

```text
unclassified points → families / trajectories / modules
weak relations       → selected explicit relations
ambient field        → structured local model
latent geography     → situated operational focus
```

Motion that only rotates, floats or glows does not satisfy `RESOLVE`.

---

## Principle D — Use one dominant visual event, not fifteen equal effects

The baseline already has many micro-elements.

The next hero should create stronger authorship by establishing **one dominant transformation** and allowing micrographics to support it.

Recommended hierarchy:

```text
1. Wordmark / proposition
2. Global system field
3. Mexico resolution event
4. Operational traces / micro-instrumentation
5. Peripheral technical texture
```

# 5. Candidate visual grammars for TECH_RESEARCH

This phase does not choose implementation. It narrows the research to three serious visual directions.

---

## DIRECTION A — Resolution Field / Local Magnification

### Visual idea

A global point/line field exists with uneven resolution. Mexico occupies a local distortion region where geometry expands, sharpens and reveals a richer relational model.

```text
GLOBAL FIELD
     ↓
LOCAL MAGNIFICATION AROUND MEXICO
     ↓
RELATIONSHIPS BECOME EXPLICIT
```

### Static-frame strength

High.

Mexico can be obviously larger even without animation.

### Motion language

```text
field bends → focus expands → selected relations stabilize
```

### Character

```text
scientific
precise
editorial
spatial
```

### Risk

Can become a gimmicky fisheye or glass lens if rendered too literally.

### Tech research questions

- Can local point-cloud deformation happen inside current Cobe geometry?
- Would a 2D/Canvas/SVG focus layer be more controllable?
- Can projection mathematics create a focus+context view without adding a full second 3D stack?

---

## DIRECTION B — System Field + Mexico Detail Inset

### Visual idea

The world remains a global systemic object, but Mexico is pulled into an enlarged secondary detail field connected to the same geometry.

Not a conventional map inset.

Think:

```text
GLOBAL MODEL
      ↘
       RESOLVED LOCAL MODEL
```

The two scales coexist.

### Static-frame strength

Very high.

No ambiguity about Mexico prominence.

### Motion language

```text
local region extracts / unfolds / resolves into detail
```

### Character

```text
technical atlas
institutional instrument
editorial system
```

### Risk

Could become a dashboard card or literal cartographic inset.

### Tech research questions

- Is the local model derived from the same geometry/data structure?
- Can the extraction be done in SVG/Canvas without duplicated heavy rendering?
- How to keep it abstract enough to avoid fake geographic analytics?

---

## DIRECTION C — Mexico as Field Attractor / Radiating System

### Visual idea

Inspired by the systems logic of Mexico 68 without copying its form: Mexico is the site where an otherwise distributed global field changes direction, density or phase.

```text
DISTRIBUTED RELATIONS
      ↓
SITUATED ATTRACTOR
      ↓
COORDINATED OUTWARD CAPABILITY
```

Instead of a lens, Mexico changes the geometry around it.

### Static-frame strength

Medium-high if the effect is sufficiently explicit.

### Motion language

```text
signals converge → relationships resolve → organized traces propagate outward
```

### Character

```text
systemic
Mexican without folklore
kinetic
graphic
```

### Risk

Could imply Mexico is the literal global center of all data or operations. Copy/layout must keep it as an art-direction focus rather than a factual claim.

### Tech research questions

- Vector-field approach vs particle advection vs SVG curves?
- Can it be deterministic and lightweight?
- How can the field remain beautiful in reduced motion/static fallback?

# 6. Preliminary visual recommendation

Do **not** choose implementation yet, but visual research currently favors a hybrid of:

```text
DIRECTION A
Resolution Field / Local Magnification

+

DIRECTION C
Mexico alters the surrounding field
```

The strongest conceptual move appears to be:

> **Mexico becomes perceptually larger because the systemic field resolves around it, not because we paste a bigger country silhouette over a globe.**

This satisfies all major invariants:

- preserves global complexity;
- makes Mexico immediately prominent;
- communicates resolution;
- avoids a literal analytics dashboard;
- allows meaningful motion;
- can retain the current editorial structure;
- creates a proprietary visual signature rather than relying solely on a recognizable point-globe component.

Direction B remains a strong fallback if technical research shows local field distortion is too expensive, fragile or hard to control.

# 8. Typography / micro-instrumentation

The baseline's tiny labels should be retained only if each can be assigned a role.

Possible semantic classes:

```text
SYSTEM CATEGORIES
  datos / sistemas / personas / instituciones

TRANSFORMATION VERBS
  observar / distinguir / modelar / relacionar / coordinar

STATE LABELS
  campo / foco / capacidad
```

Do not invent status readouts or numbers.

Microcopy can create the sense of instrumentation through **naming relationships**, not fabricated telemetry.

# 9. Motion research brief

## MOTION_PURPOSE

Make `RESOLVE` visible: a heterogeneous field gains selectively increased distinction around Mexico, then reveals an organized set of possible relations/actions.

## TRIGGER

Visual recommendation for tech research:

```text
primary = deterministic entrance / short system cycle
secondary = subtle pointer response on desktop
```

Avoid making the core concept dependent on scroll because the hero is the entry state and should communicate immediately.

## ACTIVE_DURATION

Recommended visual rhythm to test:

```text
1.2–2.4 s initial resolve event
then low-intensity idle state
```

Exact timings belong to implementation tests.

## OFFSCREEN_BEHAVIOR

No continuous expensive motion when the hero is offscreen.

The resolved still state must remain coherent.

## MOBILE_VARIANT

Preserve:

```text
global field + enlarged Mexico focus + resolved relation state
```

Reduce:

```text
point count
secondary traces
pointer behavior
long idle motion
```

## REDUCED_MOTION_VARIANT

Render directly into a strong resolved composition with only minimal opacity/state transition.

Do not revert to an undifferentiated globe.

## ESTIMATED_RUNTIME_COST

Not selected in visual research.

TECH_RESEARCH must quantitatively compare the three candidate architectures.

# 10. Still-frame gate before implementation

Before a candidate architecture is accepted in TECH_RESEARCH, ask:

```text
If motion stops at the resolved state:

[ ] Is Mexico visibly prominent within <1 second?
[ ] Is the world/system context still present?
[ ] Does the image imply selective resolution rather than a marker?
[ ] Does it avoid fake data/coverage claims?
[ ] Is the composition more authored than a stock point globe?
[ ] Can the copy remain dominant and readable?
```

If any of the first four are `NO`, reject the visual direction before coding.
