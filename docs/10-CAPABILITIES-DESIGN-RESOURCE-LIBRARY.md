# DIXIOS — Biblioteca de recursos de diseño para Capacidades

## Propósito

Esta biblioteca reúne templates, marketplaces y sistemas visuales ya construidos que pueden servir como referencia para resolver la sección **Capacidades** de la web de Dixios.

La sección contiene cinco capacidades:

1. Desarrollo de sistemas
2. Análisis y gestión de datos
3. Innovación pública
4. Asesoría
5. Capacitación

La regla de diseño de esta ronda es clara:

> No buscar un icono o un SVG aislado para cada capacidad. Buscar universos visuales completos y extraer de ellos una pieza fuerte que después se normalice con el lenguaje gráfico Dixios.

Estos recursos son **referencias visuales y productos de marketplace**. No se debe asumir que su código, imágenes, tipografías, assets o composiciones pueden copiarse directamente. Antes de reutilizar cualquier elemento se debe revisar la licencia y los términos del recurso original.

## 1. Desarrollo de sistemas

### Familia visual objetivo

**Infrastructure / architecture / operating system / industrial systems**

La representación debe comunicar infraestructura, capas, redes, arquitectura y sistema visible; no un diagrama corporativo de flechas.

### AURA OS — Framer Marketplace

https://www.framer.com/marketplace/templates/aura-os/

Elementos de interés:

- visualizaciones de infraestructura animadas;
- sistemas isométricos;
- diagramas orbitales;
- network graphics;
- microinteracciones;
- estética técnica premium;
- composición de capas y arquitectura.

**Uso Dixios:** estudiar su gramática visual de infraestructura → capas → redes → arquitectura → sistema. No copiar su identidad cromática.

### Systems — Framer Marketplace

https://www.framer.com/marketplace/templates/systems/

Elementos de interés:

- lenguaje industrial;
- minimalismo técnico;
- presentación de hardware, ingeniería y tecnología;
- estructura visual precisa.

**Uso Dixios:** referencia para presentar “Sistemas” con sobriedad y densidad técnica sin caer en diagramas genéricos.

### Atmos — Framer Marketplace

https://www.framer.com/marketplace/templates/atmos/

Elementos de interés:

- layered visuals;
- scroll interactions;
- presentación de sistemas en tiempo real;
- profundidad y jerarquía visual.

**Lectura consolidada:** la familia más prometedora para Sistemas es **isometric infrastructure + system layers + technical architecture**.

**Candidato principal:** AURA OS.

## Decisión de dirección

La sección Capacidades no debe resolverse como cinco gráficos aislados.

Debe construirse como **cinco micro-mundos visuales**: cada uno puede partir de una familia de diseño diferente, pero debe terminar normalizado por el mismo sistema Dixios de tipografía, color, geometría, ritmo, interacción y nivel de detalle.

## Siguiente ronda de investigación

Abrir visualmente entre 5 y 10 referencias por capacidad y seleccionar, para cada una:

- sección exacta;
- composición;
- sistema de movimiento;
- densidad visual;
- uso de tipografía;
- relación texto/escena;
- comportamiento responsive;
- nivel de adaptación requerido;
- posibilidad real de implementación en el stack de `webdixios`.

El resultado de esa ronda debe decidir si cada capacidad funciona mejor como card, escena, columna, panel expandible, secuencia horizontal u otra composición.

## Regla de reutilización y licencias

Antes de adoptar cualquier pieza:

1. revisar licencia y términos en la fuente original;
2. distinguir inspiración visual de código/asset reutilizable;
3. no copiar imágenes, fuentes o gráficos propietarios sin permiso;
4. documentar qué se adaptó;
5. reconstruir el resultado dentro del lenguaje visual Dixios.
